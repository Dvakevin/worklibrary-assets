# Image replacement guide

Put approved, consented media in this folder using these filenames. The page automatically uses a real image when it exists; otherwise it keeps the labeled gradient placeholder.

- `hero-video.jpg` — hero conversation image (or a poster frame)
- `topics-background.jpg` — wide conversation-topics background
- `photo-01.jpg` through `photo-10.jpg` — gallery tiles
- `mode-video.jpg`, `mode-random.jpg`, `mode-text.jpg` — three chat mode cards
- `live-01.jpg` through `live-06.jpg` — live room cards near the top of the page
- `call-01.jpg` through `call-06.jpg` — one-to-one call cards near the top of the page
- `game-01.jpg` through `game-04.jpg` — game entry cards near the top of the page

Use compressed JPG/WebP files, provide meaningful alt/context in the page, and do not imply stock or placeholder imagery is a real user if it is not.
